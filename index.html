    How do I put this file into Canvas?
    1. Click Export Canvas CSV. Look for the file in your computer’s Downloads folder.
    2. Open the correct course in Canvas and go to Grades.
    3. Choose Import from the gradebook menu, then choose your downloaded CSV file.
    4. Review the changes Canvas shows you before saving them.

    Each file is for one assignment. If you have several, choose the next assignment above and repeat.
